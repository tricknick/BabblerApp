# Babbler 0.8.5 → 1.19: автоматическое переключение раскладки

Ветка `auto-switch-0.8.5`, база — upstream `gevgeny/BabblerApp` 0.8.5. Версии 1.0–1.19.
Подробности по этапам: [RELEASE_NOTES.md](RELEASE_NOTES.md) (1.7–1.14),
[RELEASE_NOTES_1.17.md](RELEASE_NOTES_1.17.md) (1.15–1.17), [DICTIONARY.md](DICTIONARY.md).

## Коротко

Upstream Babbler менял раскладку только по нажатию клавиши (Option). Эта ветка добавляет
**автоматическое** исправление: слово, набранное не в той раскладке, исправляется само
после пробела или знака препинания — `ghbdtn` → `привет`, `руддщ` → `hello`, в обе стороны.
Слово, правильное в текущей раскладке, не трогается. Любую правку можно отменить одним
нажатием; после отмен Babbler слово запоминает.

Итог на тестовых наборах: **100 % живых фраз в обе стороны, ~97–100 % отдельных слов,
0 ошибочных правок** на 3,3 млн словарных слов, 231 тыс. слов вне словаря, брендах и именах.

## Как этого добились

- **Сначала тест, потом код.** Каждая версия начиналась с падающего теста, который
  измерял и пользу, и вред. Наборы: `tests/run.sh`, `packs_test.sh`, `lexicon_test.sh`,
  `stats_test.sh`, `context_test.sh`, `en_back_test.sh`, `yot_test.sh`, `typo_test.sh`,
  `en_probe.sh`, `scripts/run_tests.sh`.
- **Правка только при двух условиях:** слова нет в текущей раскладке и оно есть в другой.
  Незнакомое правильное слово остаётся как есть.
- **Опечатки меняют только раскладку, не текст.** `ghhbdtn` станет `прривет`, а не
  `привет`: исправлять орфографию за пользователя — другой, гораздо более рискованный шаг.
- **Каждое правило опечаток с порогом, подобранным по данным.** Без порогов замена гласных
  и перестановки давали до 19 ложных правок на 20 тыс. слов. С порогами (длина слова,
  цель — одно из 5 000 частых слов) — ноль.
- **Заглавные, ссылки, код, терминалы и IDE** — только точное совпадение или вообще без правки.

## «Ошибки будут всегда»

Будут. Цель — сделать ошибку редкой, дешёвой и неповторяющейся:

1. Худший типичный исход — слово **не** исправилось, то есть то же, что без Babbler.
2. Ложные правки измерены на миллионах слов, а не предполагаются: ноль.
3. Ошибка отменяется одним нажатием Option и запоминается.
4. Статистика в меню показывает реальную точность на твоём тексте.
5. Punto Switcher и Caramba делают это годами; Babbler делает то же локально, без сети.

## Известные ограничения

- Новые правила опечаток срабатывают, только если задуманное слово входит в 5 000 частых;
  перестановки — от 5 букв.
- ~10 % разговорных слов вне словарей не ловятся («ваще», «щаз»).
- `JSON`, `iPhone`, ВСЁ ЗАГЛАВНЫМИ — намеренно не трогаются.
- 25 редчайших RU-форм («туче», «утешен») в RU-раскладке станут английскими словами.
- После первой установки с новой подписью разрешения выдаются один раз.
