# План: обратное переключение RU → EN (английский, набранный в русской раскладке)

## Замер (tests/en_probe.sh)

| Проверка | Сейчас |
|---|---|
| 20 тыс. частотных EN-слов в RU-раскладке | 96,7 % (RU в EN-раскладке: 97,0 %) |
| 30 живых EN-предложений | 71 % слов исправлено, 0 ошибочных правок |
| Слово + точка/запятая в конце (`руддщю` → `hello.`) | 0 / 35 |
| Сокращения (`don't`, `I'm`, `it's`) | 0 / 13 |
| Слова с заглавной (`Hello`, `Monday`) — в обе стороны | никогда |
| IT/чат-сленг (lgtm, wfh, k8s) | 15 / 18 |

Вывод: словарь для английского нормальный. Живой текст портят пунктуация, заглавные, апостроф и короткие слова.

## Шаги

Каждый шаг: сначала падающий тест (тестер, haiku), потом код, потом все тесты, версия, DMG, установка.

| # | Что | Размер | Модель | Ожидаемый эффект |
|---|---|---|---|---|
| 0 | Реалистичный замер: после первой правки раскладка уже переключена, работает обратный проход по фразе | S | haiku | честная базовая цифра |
| 1 | Точка, запятая, `;` `:` `?` `!` в конце EN-слова: проверяем основу по словарю, выводим со знаком | S | haiku | 0/35 → ~35/35, главный выигрыш в живом тексте |
| 3 | Сокращения: список ~60 (`don't`, `I'm`, `we're`, `can't`…), апостроф разрешён только для них | S | haiku | 0/13 → 13/13 |
| 2 | Заглавные: `Hello`/`Привет` правится, только если точное совпадение со словарём (не опечатка и не модель); в обе стороны; прогон на ложные срабатывания по именам | M | sonnet | начало каждого предложения |
| 4 | Короткие слова в начале фразы (`I`, `to`, `me`, `so`) перед первым исправленным длинным словом | M | sonnet | +~20 % слов в предложениях |
| 5 | EN-пакет чата/IT: lgtm, wfh, imo, tbh, btw… (в «Specific vocabularies») | S | haiku | мелочи |
| 6 | Убрать ~19 редких русских форм, совпадающих с частыми EN-словами | S | haiku | +19 слов |

Порядок: 0 → 1 → 3 → 2 → 4 → 5, 6. Всего ~2 дня работы агента.

## Цель

Живые EN-предложения: 71 % → 90 %+ при 0 ошибочных правок. Каждая версия = отдельный тег (v1.15…).
