# Babbler 1.14 → 1.17: английский в обратную сторону

Ветка `auto-switch-0.8.5`, версии 1.15–1.17. Продолжение [RELEASE_NOTES.md](RELEASE_NOTES.md) (1.7–1.14).

## Коротко

В 1.14 русский, набранный в EN-раскладке, исправлялся хорошо, а английский в RU-раскладке —
заметно хуже: терялись слова с точкой или запятой в конце, сокращения (`don't`) и слова
с заглавной буквы. В 1.17 обе стороны выровнены, ошибочных правок по-прежнему ноль.

## Что сделано

| Версия | Фича | Пример |
| --- | --- | --- |
| 1.15 | Знаки в конце английского слова: `. , ; : ? ! "` | `руддщю` → `hello.`, `ерфтлыб` → `thanks,` |
| 1.15 | Английские сокращения (~60 штук), только из списка | `вщтэе` → `don't`, `цуэку` → `we're` |
| 1.16 | Слова с заглавной буквы, **в обе стороны**, только по точному совпадению со словарём | `Руддщ` → `Hello`, `Ghbdtn` → `Привет`, `Шэь` → `I'm` |
| 1.17 | Чат/IT-слова в английском словаре | `дпеь` → `lgtm`, `цар` → `wfh`, а также idk, thx, pls |
| 1.17 | Убраны 25 редчайших русских форм, совпадавших с частыми английскими словами | `цуку` → `were`, `туче` → `next`, `утешен` → `entity` |

`JSON`, `iPhone`, `GitHub`, ВСЁ ЗАГЛАВНЫМИ и смешанный регистр — по-прежнему не трогаются (намеренно).

## Почему так

- **Знаки в конце.** Точка и запятая в RU-раскладке — это буквы `ю` и `б`, поэтому
  `руддщю` раньше отвергалось как «не только буквы». Теперь знаки в конце отрезаются,
  основа проверяется по английскому словарю, а заменяется всё слово вместе со знаком.
  Настоящее русское слово на `ю`/`б` проверяется раньше и не трогается.
- **Заглавные.** Раньше любая заглавная запрещала правку — из страха испортить имя.
  Теперь `Слово` с одной заглавной проверяется как обычное, но только точным совпадением
  со словарём: без «похоже на опечатку» и без модели буквосочетаний. Имя, которого нет
  в словаре, не тронется.
- **Коллизии морфологии.** Полная русская морфология (1.8) принесла редкие формы,
  которые совпадали по клавишам с частыми английскими словами (`цуку` = `were`). Убраны
  только формы вне основного словаря, далее 280-тысячного места по частоте.

## Компромиссы

- 25 удалённых форм — настоящие, но очень редкие русские слова («туче», «утешен»,
  «кумы»). Набранные в RU-раскладке, они теперь станут `next`, `entity`, `revs`.
  Отменить — одним нажатием, после трёх отмен слово запоминается.
- `JSON`, `iPhone`, `API` в чужой раскладке по-прежнему не исправляются: риск испортить
  аббревиатуру выше пользы.
- Короткие слова (`I`, `to`, `me`) по-прежнему исправляются только обратным проходом от
  длинного слова в той же фразе. На тестовых предложениях этого хватает (100 %).
