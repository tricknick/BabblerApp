# Автопереключение раскладки: определение языка (0.8.5 → 1.24)

Ветка `auto-switch-0.8.5`, база — upstream `gevgeny/BabblerApp` 0.8.5.
В этот PR входят только изменения, связанные с определением языка при автопереключении.
Интерфейс, стабильность, установщик, подпись и статистика сюда не входят.

## Коротко

Upstream Babbler меняет раскладку только по нажатию Option. Эта ветка добавляет
**автоматическое** исправление: слово, набранное не в той раскладке, исправляется
после пробела или знака препинания — `ghbdtn` → `привет`, `руддщ` → `hello`, в обе стороны.
Слово, правильное в текущей раскладке, не трогается.

На реальных текстах (Пикабу, Хабр) переключается 73,7 / 77,8 % слов по одному
и 98,5 / 97,0 % слов во фразе целиком. Правильно набранные слова портятся
в 3 / 0 случаях из 63 тыс. слов.

## Принципы

- **Правка только при двух условиях:** слова нет в текущей раскладке и оно есть в другой.
- **Опечатки меняют только раскладку, не текст:** `ghhbdtn` → «прривет», а не «привет».
- **Пороги подобраны по данным:** без них правила опечаток давали до 19 ложных правок
  на 20 тыс. слов, с ними — ноль.
- **Заглавные, ЗАГЛАВНЫЕ, слова в скобках и сокращения** — только точное совпадение со словарём.
- **Сначала тест, потом код.** Каждое улучшение начиналось с падающего теста, который
  измерял и пользу, и вред.

## Известные ограничения

- Короткие слова (1–2 буквы: «в», «и», «на», PR, CI) по одному не переключаются,
  только по соседям во фразе.
- Незнакомые имена с заглавной («Зидана», «Акинфеев») не переключаются.
- Правила опечаток работают, только если задуманное слово входит в 5 000 частых;
  перестановки — от 5 букв.
- Около 10 % разговорных слов вне словарей не ловятся («ваще», «щаз»).
